# 組合旅行方案

1. 確認人數、機場、出發與回程日期、旅行長度、預算、行李與住宿條件。確認去回程的當地日期，檢查跨日、跨時區及轉機時間。
2. 用已核對來源選一個具名住宿首選與實質備案，附地區、日期、房型、入住條件、必要交通和查價時間。費用若有取消條件或稅費差異，一併列出。
3. 串起出門、航班、機場接駁、入住、日程與返程。核對全年行程管理員回覆的時段是否包含完整旅程及緩衝。
4. 列整趟費用口徑。區分已核對價、估算、未知項目和幣別；標明每人和全團金額。對可能變動的價格附查詢時間與來源。
5. 指出為何推薦、哪些條件仍待確認，以及使用者下一步需要決定的事項。訂位、付款、改票與取消由使用者逐次確認。
## 照片與評價

每個推薦的住宿或溫泉館都附上，讓使用者一眼看出值不值得去：

- 一張外觀、房間或湯屋照片：只能用 shared/travel-workflow/place-photo.py 從這間自己的官網或訂房頁存下（它會確認照片真的在那一頁上），把它印出的 `MEDIA:` 行和說明行原樣貼上，Telegram 會顯示成圖片。不准用其他來源的圖或示意圖；找不到就寫「照片：未取得」。
- 評分：Google 地圖星等與評論數；有 Booking 或 Agoda 也附分數。註明查詢日期。
- 評論重點：用自己的話各摘要一句近期評論的優點和缺點，不整段複製。
- 手機排版：每間一個短段落，照片放在段落前；分數和評論重點各一行。
